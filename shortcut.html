Save from any app

Once it's set up, tap Share on a post in any app, then bruh, and the photos or videos go straight into Photos. Single posts, boards and profiles all work.

Your address

The Shortcut can't use your login, so its address carries your passcode. Type it to build the address. It stays on this page and isn't sent anywhere.

Build it

  1. Open Shortcuts, tap +, and name it bruh.
  2. Tap ⓘ, turn on Show in Share Sheet, and set it to receive URLs and Text.
  3. Add URL Encode. It encodes the Shortcut Input, the link you shared.
  4. Add Text. Paste your address, then insert the variable URL Encoded Text at the very end.
  5. Add Get Contents of URL. It uses the Text above.
  6. Add Split Text, split by New Lines.
  7. Add Repeat with Each.
  8. Inside the repeat, add Get Contents of URL using Repeat Item.
  9. Inside the repeat, add Save to Photo Album.
  10. Try it: Share a post, tap bruh, and choose Always Allow when asked.

If nothing saves, run the shortcut on a copied link and check what the first Get Contents of URL returns. It will say what went wrong, for example "Wrong passcode".
